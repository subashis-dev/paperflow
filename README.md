# PaperFlow — Academic Methodology & System Architecture Studio 📊✨

> **The Modern, High-Craft Methodology Diagram Designer for Researchers & Engineers.** Create publication-ready deep learning pipelines, system architectures, and scientific methodology flowcharts ready for IEEE, Springer, ACM, and Elsevier.

🌐 **Live Demo:** [https://subashis-dev.github.io/paperflow/](https://subashis-dev.github.io/paperflow/)

---

## 🌟 Highlights

- **Specialized Academic Block Library:** Built specifically for research methodologies:
  - 📷 **Data Collection & Class Lists:** Image collages, class lists, and raw corpus cards.
  - ⚙️ **Data Pre-Processing:** Tokenization, stemming, data augmentation, gray scaling, and filter rule callouts.
  - 🧠 **Feature Extraction:** Deep feature extractors, CBOW & Skip-Gram embeddings.
  - 🥧 **Data Split (Pie Chart):** Dynamic training / validation / test partition charts with branching pills.
  - 🧩 **DL & ML Algorithms Container:** Neural ensemble boxes with badges for `CNN`, `LSTM`, `MobileNet`, `VGG`, `ResNet`, `EfficientNet`, `SVM`, `Random Forest`.
  - 🎯 **Trained Models:** Neural architecture checkpoints and validation summaries.
  - 📊 **Evaluation Trees:** Hierarchical metrics for `Accuracy`, `Precision`, `Recall`, and `F1 Score`.
  - 📈 **Prediction Outputs:** Positive / Negative classification branches or generated captions.
- **1-Click Preset Academic Templates:** Instantly load full methodology architectures:
  1. *Deep Learning Vision & Object Framework*
  2. *NLP Sentiment & Text Classification Pipeline*
  3. *Multimodal Image Caption Generator*
  4. *Sovereign Edge Voice AI Architecture*
- **Publication-Ready Export Suite:**
  - 🖼️ **300 DPI High-Res PNG:** Crisp, unpixelated export for journal & conference submission.
  - 📐 **Vector SVG:** Infinitely scalable vector graphics for LaTeX and Overleaf (`\includesvg`).
  - 💾 **Draw.io (.drawio) XML Export:** Native compatibility with [draw.io](https://app.diagrams.net).
  - 📦 **Save & Load Project (.paperflow):** Re-open and edit your diagrams anytime.
- **Modern Interactive Canvas:** Smooth panning, mouse-wheel zoom with cursor focal tracking, snap-to-grid, undo/redo (`Ctrl+Z` / `Ctrl+Y`), duplicate (`Ctrl+D`), and dynamic color palettes.
- **100% Client-Side & Sovereign:** Zero tracking, zero telemetry, runs directly in your browser with no backend or account required.

## 🚀 How to Run Locally

Simply open `index.html` in any web browser:
```bash
# Clone the repository
git clone https://github.com/subashis-dev/paperflow.git
cd paperflow

# Open in browser directly or serve with python:
python -m http.server 8080
```
Visit **[http://localhost:8080](http://localhost:8080)**.

---

## 🌐 Deploy to GitHub Pages (1 Step)

1. Go to your repository on GitHub: `https://github.com/subashis-dev/paperflow`
2. Click **Settings** ➔ **Pages** (left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save** — your studio is instantly live at:
   👉 **`https://subashis-dev.github.io/paperflow/`**
