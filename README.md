# PaperFlow — Academic Methodology & System Architecture Studio 📊✨

> **The Modern, High-Craft Methodology Diagram Designer for Researchers & Engineers.** Create publication-ready system architectures, scientific flowcharts, and multi-stage pipelines ready for IEEE, Springer, ACM, and Elsevier.

🌐 **Live Website:** [https://subashis-dev.github.io/paperflow/](https://subashis-dev.github.io/paperflow/)

---

## 🌟 Highlights

- **Clean Modular Shapes & Icons Library:**
  - 🎨 **Visual Icon Picker:** Select from 30+ scientific and engineering icons (AI Brain, Data Storage, Vision/Camera, Evaluation Metrics, Process Sliders, Containers, Comparison, Funnel, etc.).
  - 🔲 **Process Step Cards:** Modular computation and transformation steps with customizable titles, descriptions, and colors.
  - 🗄️ **Data & Input Blocks:** Source dataset and input tensor blocks.
  - 🧠 **Model & Algorithm Boxes:** Neural models, candidate architectures, and learning components.
  - 🥧 **Split & Partition Charts:** Dynamic training / validation / test partition charts.
  - 🏷️ **Labels & Status Pills:** High-contrast classification and data tags.
  - 📊 **Metrics & Evaluation:** Score checklists and benchmark summaries.
  - 🗂️ **Pipeline Stage Containers:** Large bounding frames to group sub-stages into clear conceptual modules.
  - 🌪️ **Funnel Screening Stages:** Multi-stage filtering cards with directional metric transitions.
  - ⚖️ **A/B Comparison Cards:** Dual-branch parallel architecture comparison cards.
  - 👤 **Perception & Study Cards:** Evaluation cards with criteria question prompts.
- **Publication-Ready Export Suite:**
  - 🖼️ **300 DPI High-Res PNG:** Crisp, unpixelated export for journal & conference submission.
  - 📐 **Vector SVG:** Infinitely scalable vector graphics for LaTeX and Overleaf (`\includesvg`).
  - 💾 **Draw.io (.drawio) XML Export:** Native compatibility with [draw.io](https://app.diagrams.net).
  - 📦 **Save & Load Project (.paperflow):** Re-open and edit your diagrams anytime.
- **Modern Interactive Canvas:**
  - Smooth panning, mouse-wheel zoom with cursor focal tracking, snap-to-grid, undo/redo (`Ctrl+Z` / `Ctrl+Y`), duplicate (`Ctrl+D`), and dynamic color palettes.
- **100% Client-Side & Sovereign:**
  - Zero tracking, zero telemetry, runs directly in your browser with no backend or account required.

## 🚀 How to Run Locally

Simply open `index.html` in any web browser:
```bash
# Clone the repository
git clone https://github.com/subashis-dev/paperflow.git
cd paperflow

# Open in browser directly or serve with python:
python -m http.server 8080
```
Visit **[http://localhost:8080](http://localhost:8080)**.

---

## 🌐 Deploy to GitHub Pages

1. Go to your repository on GitHub: `https://github.com/subashis-dev/paperflow`
2. Click **Settings** ➔ **Pages** (left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save** — your studio is instantly live at:
   👉 **`https://subashis-dev.github.io/paperflow/`**
